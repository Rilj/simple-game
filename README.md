# Simple Game

A fast-paced neon-themed arcade survival game built with vanilla JavaScript and HTML5 Canvas.

## Overview

Navigate your ship through an endless void, dodging obstacles and collecting power-ups. Built with pure vanilla JS, no external dependencies.

## Features

- **Fast-paced gameplay** - Increasing difficulty with faster obstacles
- **Dual-dash mechanic** - Dash through obstacles with limited energy
- **Collectibles** - Chain multipliers and refill dash energy
- **Neon aesthetics** - Glowing visuals with particle effects
- **Responsive** - Desktop (keyboard) and mobile (touch) support
- **Progressive difficulty** - Game speeds up as you travel further

## Controls

| Action | Keyboard | Mobile |
|--------|----------|--------|
| Move | Arrow keys / WASD | Touch zones |
| Dash | Spacebar | Right touch zone |
| Pause | Escape | N/A |

## Quick Start

```bash
# Using a local server (recommended)
python -m http.server 8000

# Or just open directly
# Double-click index.html
```

Then visit `http://localhost:8000`

## Tech Stack

- HTML5 Canvas for rendering
- Vanilla JavaScript (ES6)
- CSS Grid & Flexbox for layout
- Web Audio API for sound
- localStorage for high scores
